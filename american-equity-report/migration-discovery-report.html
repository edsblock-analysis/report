American Equity is a marketing/content site on Optimizely CMS with a Next.js front end. Because the DOM labels every component with a data-component name, block boundaries and their per-template placement are read from the markup. All 74 URLs returned HTTP 200; 10 are legacy 301/308 redirects to canonical pages, leaving 64 distinct rendered pages across 11 templates. The EDS build surface is 16 blocks (13 content + 3 global) with 25 variations. Block complexity: High 5   Low 3   Medium 8.

For estimation & the customer conversation, the drivers are: (a) the Tabs block and the two client-hydrated listings (Insights feed + searchable form/document libraries) that need an EDS index with search/pagination — the main net-new data-modeling work; (b) third-party embeds — ion interactive forms, Hedgeness calculator, Greenhouse jobs — which are preserved and integrated the same way they run today, not rebuilt; (c) global chrome (mega-menu header, footer, breadcrumb) built once.
Explicitly OUT of EDS scope (link, don't rebuild): customer Login (myportal) and Register (register, Okta) redirect to separate subdomain applications; affiliate sites (eagle-lifeco, ae-newyork); DAM downloads (asset.american-equity.com) and the /api/assets/resolve-by-key resolver (a verified 301 redirect, not custom code); and the vendor-hosted forms/calculator/jobs apps.

10 · Other Observations

Source platform
Next.js (App Router / RSC) on Optimizely CMS (SaaS), server envoy. Blocks are read from the site's own data-component attributes, so the block/template mapping is evidence-based, not inferred.
Migration content source
Content re-authored from Optimizely into EDS documents (Google Drive / SharePoint or DA). Because components are explicitly named, block boundaries map deterministically to EDS blocks.
Client-hydrated content
The Insights feed and the form/document libraries render their lists client-side (empty in server HTML). These need EDS index-backed listing blocks — the main net-new data-modeling effort.
Asset resolver
/api/assets/resolve-by-key (17 pages) is a verified 301 asset resolver to asset.american-equity.com (returns a PDF). It is a redirect/download service, not custom application code — reuse it.
Login / Register
Header/footer Login and Register link to separate subdomain applications (portal + Okta). Out of EDS scope — preserve links, do not rebuild.
Video
Wistia is the only on-page video (14 pages) via the <wistia-video> web component; YouTube appears only as outbound links. Use a lazy facade + delayed script for CWV.
SEO & accessibility
All 74 pages carry meta descriptions and canonicals; 10 pages have more than one H1 — normalize during migration. Preserve data-gtm-* attributes for analytics parity; maintain ARIA on nav/tabs/accordions/modal.
No CAPTCHA in AE markup
No reCAPTCHA/hCaptcha/Turnstile in American Equity's own markup. Any CAPTCHA lives inside vendor iframes (ion / Greenhouse) and is not verifiable from the accessible page behavior.
Redirects
10 of 74 input URLs are 301/308 redirects to canonical pages, leaving 64 distinct rendered pages. Recreate these in EDS redirect config.
